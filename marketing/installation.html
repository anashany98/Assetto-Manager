GUÍA RÁPIDA DE INSTALACIÓN

Instala Assetto Manager en LAN con garantías

Este documento resume el despliegue típico: PC Master (backend + panel) y Agentes en cada simulador. Para detalles avanzados, usa la Wiki.

01

Servidor Master (Recepción)

El Master aloja la API (puerto 8000) y el panel web (puerto 3010).

Instalar dependencias 

cd C:\AssettoManager
install_dependencies.bat

Requiere Node.js y Python (ver wiki).

Arrancar el sistema 

start_system.bat
API: http://127.0.0.1:8000
Panel: http://127.0.0.1:3010
LAN: para que los agentes conecten, el backend debe escuchar en tu IP LAN y el firewall debe permitir el puerto 8000. Ver detalles en Wiki » LAN y Puertos.
02

Agentes (cada simulador)

El agente mantiene el simulador controlado: estado online, telemetría, comandos remotos y sincronización.

Copiar carpeta

Copia agent/ al PC del simulador, por ejemplo: 

C:\AssettoManager\agent\

Configurar y arrancar

Ejecuta el instalador del agente (crea venv, instala deps y genera config.json): 

cd C:\AssettoManager\agent
setup.bat
Importante: en config.json el server_url debe ser la IP del Master, por ejemplo http://192.168.1.50:8000.
03

Licencia por módulos

Assetto Manager funciona por módulos licenciados. Sin licencia válida, la app ocultará módulos no autorizados.

Activar licencia

Pega el token de licencia en el panel: 

Configuración → Licencia

La licencia es un JWT firmado (RS256). No se envían datos de telemetría al exterior.

Ver módulos activos

Desde el panel puedes comprobar qué módulos están habilitados por licencia. 

API: GET /license
Más detalles en Wiki » Licencias.
